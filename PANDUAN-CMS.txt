========================================================================
 BARU NGEH — Situs versi CMS (bisa diedit lewat web)
 Panduan setup dari nol. Ikutin urut, sekali doang kok setup-nya.
========================================================================

Yang bakal lo dapetin di akhir:
- Situs tetap https://barungeh.netlify.app (desain sama persis).
- Panel admin di https://barungeh.netlify.app/admin buat nulis cerita/
  riddle kayak WordPress, tanpa nyentuh kode.
- Tiap lo klik "Publish", situs update sendiri dalam ~1 menit.

Mesin di baliknya: Eleventy (perakit) + GitHub (penyimpan) +
Netlify (deploy) + Decap CMS (editor) + DecapBridge (login).

CATATAN STRUKTUR: isi ZIP ini adalah "root" repo. Waktu upload ke
GitHub, file package.json / folder src / admin HARUS ada di paling
luar repo, JANGAN kebungkus folder lagi.

------------------------------------------------------------------------
FASE 1 — BIKIN AKUN & REPO GITHUB
------------------------------------------------------------------------
1. Buka github.com, klik "Sign up". Bikin akun (gratis). Verifikasi email.
2. Setelah login, klik ikon "+" kanan atas > "New repository".
3. Repository name: barungeh
   - Visibility: Public (boleh; lebih gampang). Private juga bisa.
   - JANGAN centang "Add a README" (biar repo bener-bener kosong).
   - Klik "Create repository".
4. Di halaman repo kosong, klik link "uploading an existing file"
   (ada di tulisan "...or upload an existing file").
5. Extract ZIP ini dulu di komputer, lalu SELECT SEMUA isinya
   (package.json, netlify.toml, .eleventy.js, .gitignore, folder src,
   folder admin, file panduan) dan seret ke area upload GitHub.
   -> Pastikan yang keupload adalah ISI-nya, bukan folder pembungkus.
6. Di bawah, klik "Commit changes". Selesai fase 1.
   (Ingat username GitHub lo, misal "ahdan123". Nanti kepakai.)

------------------------------------------------------------------------
FASE 2 — SAMBUNGIN KE NETLIFY (deploy dari Git)
------------------------------------------------------------------------
Catatan: kalau situs barungeh.netlify.app yang lama dibikin lewat
drag-drop, kita ganti jadi deploy-dari-Git. Cara paling rapi: bikin
site baru dari Git, lalu pindahin nama "barungeh" ke situ.

1. Buka app.netlify.com > "Add new site" > "Import an existing project".
2. Pilih "Deploy with GitHub", authorize, lalu pilih repo "barungeh".
3. Build settings biasanya kebaca otomatis dari netlify.toml:
   - Build command : npm run build
   - Publish dir   : _site
   Kalau kosong, isi manual seperti di atas. Klik "Deploy".
4. Tunggu build selesai (hijau). Situs udah online di URL acak dulu.
5. Site configuration > Change site name > isi "barungeh".
   - Kalau nama "barungeh" masih nyangkut di site lama, hapus/rename
     site lama dulu, baru set yang ini jadi "barungeh".
   Hasil akhir: https://barungeh.netlify.app jalan dari Git.

Mulai sekarang: tiap ada perubahan di repo (termasuk dari CMS),
Netlify rebuild otomatis. Nggak ada drag-drop lagi.

------------------------------------------------------------------------
FASE 3 — SETUP LOGIN CMS (DecapBridge, gratis)
------------------------------------------------------------------------
1. Buka decapbridge.com, "Sign up" (bisa pakai Google).
2. Di dashboard, "Add site" / "Create site":
   - URL CMS  : https://barungeh.netlify.app/admin/
   - Hubungin / authorize repo GitHub "barungeh".
3. DecapBridge bakal ngasih 3 nilai. Catat:
   - repo         : <username>/barungeh
   - identity_url : https://auth.decapbridge.com/sites/<site-id>
   - gateway_url  : https://gateway.decapbridge.com

4. Masukin 3 nilai itu ke file admin/config.yml (baris yang ada
   tulisan GANTI-...). Cara paling gampang lewat GitHub:
   - Buka repo > folder admin > file config.yml > klik ikon pensil.
   - Ganti:
       repo: GANTI-USERNAME/barungeh          -> repo: <username>/barungeh
       identity_url: .../sites/GANTI-SITE-ID   -> tempel identity_url dari DecapBridge
     (gateway_url biasanya udah bener.)
   - "Commit changes". Netlify rebuild otomatis (~1 menit).

5. Di DecapBridge, buka "Manage collaborators" > undang email lo
   sendiri. Cek email, klik link, set password / pilih login (Google).

------------------------------------------------------------------------
FASE 4 — COBA NULIS
------------------------------------------------------------------------
1. Buka https://barungeh.netlify.app/admin
2. Login (email+password atau Google, sesuai yg lo set di fase 3).
3. Lo bakal liat 2 koleksi: "Riddle" dan "Cerita".
   - Di dalamnya udah ada beberapa DRAFT (judul yang dulu ada di situs).
     Statusnya "draft" karena "Tayangkan sekarang?" masih OFF.
4. Klik salah satu, tulis isinya, isi ringkasan, (buat riddle: tambah
   pilihan jawaban + level), lalu NYALAIN toggle "Tayangkan sekarang?".
5. Klik "Publish" > "Publish now".
6. Tunggu ~1 menit, refresh situsnya. Kartunya muncul, halamannya jadi.

Nambah konten baru = tombol "New Riddle" / "New Cerita" di CMS.
Draft (toggle OFF) nggak muncul di situs publik dan nggak keindeks
Google, jadi aman buat nyimpen tulisan setengah jadi.

------------------------------------------------------------------------
MASIH PERLU DIISI SENDIRI
------------------------------------------------------------------------
- Kontak di halaman Kebijakan Privasi (buat AdSense). File-nya:
  src/kebijakan-privasi.njk, bagian "8. Kontak" -> ganti jadi email
  resmi lo. Edit lewat GitHub (ikon pensil) lalu commit.

------------------------------------------------------------------------
CARA EDIT DESAIN / HALAMAN STATIS (opsional, jarang)
------------------------------------------------------------------------
- Teks homepage, Video, Submit, Tentang: ada di src/index.njk,
  src/video.njk, src/submit.njk (edit lewat GitHub, commit, auto-deploy).
- Tampilan/warna: src/assets/styles.css
- Logika interaktif (share, countdown, cookie, filter): src/assets/app.js
- URL Facebook & site: udah di-set ke akun lo di app.js dan config.

Kalau butuh, homepage juga bisa dijadiin bisa-diedit-lewat-CMS nanti
(pakai "file collection"). Bilang aja kalau mau ditambahin.
